# Вебхук Google Таблицы + Telegram (SSP-Agency)

## Инструкция:
1. Создайте Google Таблицу.
2. Откройте **Расширения ➔ Apps Script**.
3. Вставьте код из `webhook.gs`.
4. Впишите свои `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. Нажмите **Развернуть ➔ Новое развертывание ➔ Веб-приложение** (доступ: "Все").
6. Скопируйте полученный URL — форма шлет данные на него.
