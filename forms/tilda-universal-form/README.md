# Универсальная форма для Тильды (SSP-Agency)

## Возможности:
- Строго 1 видимое поле телефона (дубли мессенджеров скрыты).
- Нативный выбор стран из 200+ направлений с флагами.
- Мобильный адаптив (без отступов, номер виден целиком).
- 4 канала связи (Телефон / Telegram / WhatsApp / MAX).
- Автоматический сбор UTM-меток, гео, реферера в скрытый комментарий.

## Установка:
Добавить блок T123 (HTML) на страницу Тильды и вставить содержимое `form.html`.
