# Золотой фонд эталонов SSP-Agency

Центральный репозиторий готовых решений и модулей для всех проектов:

## 📁 Структура:
- **forms/tilda-universal-form/**: Эталонная форма для любых проектов на Тильде (один телефон, маски, флаги стран, сбор UTM).
- **webhooks/google-sheets-telegram/**: Вебхук для приема лидов без абонентской платы (Google Таблица + Telegram).
- **scripts/**: Универсальные скрипты аналитики, антифрода и трекинга.
